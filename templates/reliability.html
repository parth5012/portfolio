// how I found these

Not by reading the code. By trying to break it: submitting the contact form empty, then with garbage, then twice as fast as a person can click; setting the classifier to stub mode and reading what the eval actually scored; injecting a deliberately broken URL into the scraper and checking whether the other fifty-nine records still landed; and removing the environment variable the contact form needs to see whether it would tell the truth or pretend.

The last one is the reason this page exists. An earlier version of this site's contact form faked a success message and dropped every message on the floor. Now, with no webhook configured, it returns an honest error instead. Same for the classifier: the live-model score is listed as missing rather than quietly replaced by the stub number, which would have looked better and been a lie.

// what I will fix next

Recording the classifier's live-model score, then extending the eval set so urgency is scored and not just returned. Until both are done this case is honestly described as measured on category only, which is what the reliability page says it is.
